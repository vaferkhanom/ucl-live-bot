# UCL Live Bot ⚽🤖

بات تلگرامی پوشش **لحظه‌ای** بازی‌های چمپیونزلیگ برای گروه‌ها — دقیقاً با فرمت کانال‌های لايو معروف، با **ادیت پیام** به‌جای اسپم.

## ویژگی‌ها

- ⚽ **گل** → اول پیام با اسم گلزن؛ وقتی اسیست مشخص شد **همون پیام ادیت میشه** و اسیست اضافه میشه
- ❌ **گل مردود (آفساید/فول)** → همون پیام گل به «GOAL DISALLOWED» ادیت میشه (نه پیام جدید!)
- 🟨 کارت زرد / 🟥 قرمز / 2nd yellow
- 🥅 پنالتی: اعلام پنالتی، پنالتی خورده‌شده (SAVED) و از دست رفته (MISSED)
- 🔄 تعویض‌ها
- 🟢 شروع بازی، 🏁 HT و FT
- 🏁 **HT/FT با امتیاز فانتزی** مثل `16 - O. Dembélé` (تخمین بر اساس فرمول UCL Fantasy از آمار واقعی ESPN)
- 📊 جدول آمار پایان بازی (Possession، Shots، Corners، Saves، ...)
- 📋 **LINEUPS** خودکار وقتی ترکیب‌ها منتشر میشه
- 🔇 **سیستم ضد اسپویل (Mute)**: قبل بازی با `/mute` بازی مورد نظر رو قطع کن — اونوقت بات **هیچ پیامی** از اون بازی نمی‌فرسته (نه حتی ادیت). با `/unmute` برگرده.
- دیتابیس SQLite — بعد از ری‌استارت هیچ ایونت تکراری نمی‌فرسته

## دیتاسورس

**سه منبع، ترکیب شده (اولویت ۱ = سرعت خبر):**
- **FotMob API** — **ناشر اصلی ایونت‌ها**: گل + اسیست inline، کارت، تعویض، پنالتی. پولینگ ~۲ ثانیه با ETag/304. در ریس زنده ۶۰–۸۰ ثانیه از 365scores جلو زد
- **365scores live** — واچ‌داگ (~30KB) + محرک فوری ESPN روی تغییر اسکور
- **ESPN** — آمار، لیست فانتزی، ترکیب‌ها (lineups) و پشتیبان ایونت (با dedupe دوسویه)
- پولینگ کامل ESPN هر `POLL_SECONDS` (پیش‌فرض ۱۰ ثانیه) + کش CDN فقط ۱–۶ ثانیه

## دیپلوی روی Railway

1. این ریپو رو تو Railway از گیت‌هابت Import کن (New Project → Deploy from GitHub repo)
2. تو قسمت **Variables** این دو تا رو بذار:
   - `BOT_TOKEN` = توکن بات از BotFather
   - `OWNER_ID` = آیدی عددی تلگرامت (مثلاً `6437188126`)
3. Start command پیش‌فرض از Dockerfile میاد — فقط Deploy بزن ✅
4. بات رو به گروهت اضافه کن و **بده دسترسی ارسال/ادیت پیام**
5. اولین پیام `/start` رو بده تا گروه تو دیتابیس ربات ذخیره بشه

> ⚠️ مهم: بات باید موقع `/start` تو گروه حاضر باشه؛ عضویتش تو گروه خودکار ذخیره میشه.

## متغیرهای محیطی (اختیاری)

| متغیر | پیش‌فرض | توضیح |
|---|---|---|
| `BOT_TOKEN` | — | **اجباری** — توکن BotFather |
| `OWNER_ID` | — | **اجباری** — آیدی عددی ادمین |
| `POLL_SECONDS` | `10` | فاصله پولینگ بازی زنده |
| `SCOREBOARD_SECONDS` | `90` | فاصله بروزرسانی لیست بازی‌ها |
| `STATS_BLOCK` | `1` | جدول آمار در FT |
| `LINEUPS` | `1` | ارسال خودکار ترکیب‌ها |
| `FANTASY` | `1` | بلوک امتیاز فانتزی در HT/FT |
| `POINTS_LIST_MAX` | `14` | حداکثر خطوط امتیاز |
| `KICKOFF_MSG` | `1` | پیام شروع بازی |
| `LEAGUE_SLUG` | `uefa.champions` | مثلاً `uefa.europa` برای لیگ اروپا |

## اجرای لوکال

```bash
pip install -r requirements.txt   # در واقع هیچی نصب نمیشه، stdlib فقط
export BOT_TOKEN=... OWNER_ID=...
python bot.py
```

## تنظیم امتیاز فانتزی

فرمول تو `config.py` (بخش `POINTS`) هست. اگه با اپ رسمی اختلاف دیدی، فقط همون دیکشنری رو تغییر بده.

## دستورات

| دستور | توضیح |
|---|---|
| `/today` | لیست بازی‌های امروز و فردا (با ساعت تهران) |
| `/mute` | انتخاب بازی برای قطع نوتیف (دکمه‌ای) |
| `/unmute` | وصل کردن دوباره |
| `/mutes` | لیست موت‌شده‌ها |
| `/status` | وضعیت ربات |

دستورات فقط برای `OWNER_ID` کار می‌کنن.
